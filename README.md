# Jumper Kiddon
A game made with Godot

### Gameplay
- A game adapted from Google Dino game, it's an upgraded version,
it contains upgrades, like coins, shield, super dash.

### Controls
- Jump: W-Up Arrow-Space-Enter (You can double jump)
- Duck: S-Dn Arrow

### Target
- You have to collect 100 coins to reach the prize!
